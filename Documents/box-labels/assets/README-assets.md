# راهنمای پوشه assets

این پوشه تصاویر مورد نیاز لیبل‌های جعبه محصول RODI را نگهداری می‌کند.

## فایل‌هایی که باید در این پوشه قرار دهید:

| نام فایل | وضعیت | مشخصات |
|----------|--------|---------|
| `logo-rodi.png` | ⏳ منتظر | لوگوی برند RODI — PNG با پس‌زمینه شفاف، حداقل 400×160px |
| `qr-website.png` | ⏳ منتظر | QR Code سایت rodiset.ir — PNG حداقل 200×200px |
| `qr-connect.png` | ⏳ منتظر | QR Code اتصال به دستگاه RODI — PNG حداقل 200×200px |

## نکات مهم:

- نام فایل‌ها باید **دقیقاً** همین باشد (حروف کوچک، خط تیره)
- فرمت PNG توصیه می‌شود
- لوگو باید پس‌زمینه شفاف (transparent) داشته باشد
- QR Code باید کیفیت بالا و بدون blur باشد تا قابل اسکن باشد

## فایل‌هایی که نیازی به تهیه ندارند:

آیکون‌های هشدار، آب، و تهویه به صورت SVG مستقیم در کد HTML نوشته می‌شوند.
