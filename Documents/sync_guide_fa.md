# راهنمای آسون کردن فایل پروپوزال با گوگل داکس

## مشکل شما چیه نمیدانم شما چطور ؟

فایل پروپوزال روی لپ تاپ تون هست، می‌خواید از گوگل داکس هم استفاده کنید، و هر وقت یکی تغییر بدهد، اون یکی هم خودکار بروز شود.

## ✅ راه‌های ممکن (از آسان تا سخت)

### **راه اول: فایل رو کپی کنید توی گوگل داکس (ساده‌ترین)**

**چجوری کار می‌کنه؟**

- فایل پروپزال‌تون رو باز کنید  
- کل متن رو کپی کنید (Ctrl+A، بعد Ctrl+C)  
- یک گوگل داک جدید بسازید  
- متن رو اونجا پیست کنید  
- لینک‌اش رو با دوستان به اشتراک بذارید

**مزایا:** ✓ خیلی ساده و سریع  
✓ هیچ نصب برنامه‌ای لازم نیست  
✓ بهترین ویرایش و نظر‌دهی  
✓ کار تیمی خوب

**معایب:** ✗ فایل لپ تاپ و گوگل داک جدا می‌مونن (یکی دیگه رو بروز نمی‌کنن)  
✗ دستی باید همزمان شون کنید  
✗ بدجور گیج‌کننده اگه هر دو جا تغییر بدهید

**راه شورتکات برای اشتراک:**

1. گوگل داک رو بسازید  
2. بالای صفحه روی **"اشتراک‌گذاری"** کلیک کنید  
3. ایمیل دوستان رو بنویسید یا **"هر کسی می‌تواند ویرایش کند"** رو انتخاب کنید

---

### **راه دوم: Google Drive Desktop \+ دوطرفه‌سازی (متوسط)**

**چجوری کار می‌کنه؟**

- برنامه **Google Drive for Desktop** را نصب کنید (رایگان)  
- فایل پروپزال‌تون رو توی پوشه Google Drive قرار بدید  
- خودکار طور فایل با گوگل درایو هم‌رسانی می‌شه  
- فایل رو گوگل داک قالب‌بندی کنید

**مراحل:**

1. **نصب برنامه:**  
     
   - برید https://www.google.com/drive/download/  
   - دانلود و نصب کنید  
   - با حسابتون لاگین کنید

   

2. **فایل رو آپلود کنید:**  
     
   - فایل پروپوزال رو درگ کنید توی پوشه Google Drive  
   - یا توی Google Drive وب‌سایت، فایل رو درگ کنید

   

3. **تبدیل کنید:**  
     
   - توی Google Drive، روی فایل راست کلیک کنید  
   - **"باز کردن با" → "Google Docs"** کنید (اگه Word باشه)  
   - این کار یک نسخه Google Docs از فایلتون می‌سازه

**مزایا:** ✓ خودکار‌تر از راه اول  
✓ فایل لپ تاپ خودکار بروز می‌شه  
✓ گوگل داک هم خودکار بروز می‌شه  
✓ برای تیم بسیار خوب است

**معایب:** ✗ نیاز به اینترنت مرتب دارید  
✗ فایل اصلی و Google Docs نسخه‌های جداگانه‌ای هستند  
✗ اگه دوجا یکجا تغییر بدهید، مشکل ممکن است

---

### **راه سوم: Google Apps Script (پیشرفته)**

**چجوری کار می‌کنه؟**

- یک اسکریپت می‌نویسند که هر وقت فایل تغییر بکند، گوگل داک رو بروز کند  
- سخت‌تره اما بهترین‌تره\!

**نیاز دارید:**

- کمی دانش برنامه‌نویسی (یا کپی-پیست کردن کد\!)  
- گوگل داک فعال

**نکات:**

- خیلی پیچیده اگر بخواید خودتون بنویسید  
- اگه بخواید استفاده کنید، از کسی که تجربه دارد کمک بگیرید

---

## 🎯 بهترین انتخاب برای شما؟

**اگه فقط می‌خواید با دوستان به اشتراک بذارید:**  
👉 **راه اول** (کپی و پیست)

**اگه می‌خواید خودکار‌تر و درست‌تر:**  
👉 **راه دوم** (Google Drive Desktop)

**اگه می‌خواید کاملاً خودکار و دقیق:**  
👉 **راه سوم** (اسکریپت) \+ **کمک کسی باتجربه**

---

## 📋 مراحل تفصیلی برای راه دوم (بهترین\!)

### **مرحله ۱: نصب Google Drive Desktop**

1\. اینجا برید: https://www.google.com/drive/download/

2\. دکمه "Google Drive for Desktop" رو کلیک کنید

3\. فایل نصب‌کننده رو دانلود کنید

4\. دوبار روش کلیک کنید و نصب کنید

5\. حساب گوگل‌تون رو انتخاب کنید

### **مرحله ۲: فایل رو آپلود کنید**

1\. فایل پروپزال (Word/PDF) رو باز کنید

2\. Ctrl+A (انتخاب‌اش کنید)

3\. Ctrl+C (کپی کنید)

4\. برید به google.com/drive

5\. روی دکمه "+" کلیک کنید

6\. "اپلود فایل" انتخاب کنید

7\. فایل‌تون رو انتخاب کنید

### **مرحله ۳: تبدیل به Google Docs**

1\. فایل آپلود‌شده رو سمت‌راست کلیک کنید

2\. "باز کردن با" → "Google Docs"

3\. یک نسخه جدید Google Docs می‌سازه

4\. الان میتونید از هر دو نسخه استفاده کنید

### **مرحله ۴: به اشتراک بگذارید**

1\. نسخه Google Docs رو باز کنید

2\. روی دکمه "اشتراک‌گذاری" کلیک کنید

3\. ایمیل دوستان رو بنویسید یا

4\. لینک عمومی بسازید و بفرستید

## ⚠️ محدودیت‌ها

### **محدودیت‌های تمام راه‌ها:**

- **نیاز به اینترنت:** بدون اینترنت، بروز‌رسانی‌های زنده کار نمی‌کنند  
- **تاخیر:** بروز‌رسانی‌های آنی نیستند، ۵-۲۰ ثانیه تأخیر دارن  
- **نسخه‌های جدا:** Google Docs و فایل اصلی جدای هم می‌مونن

### **مشکل اصلی:**

اگه دو نفر **همزمان** در دو جای مختلف (لپ تاپ و گوگل داکس) تغییر بدهند، ممکن است:

- یک تغییر از دست برود  
- یک نسخه دیگری ایجاد شود

**حل:** یکی فقط لپ تاپ کار کند، یکی فقط گوگل داکس\! (بهترین روش)

---

## 💡 نکات کاربردی

### **۱. تاریخچه تغییرات**

توی گوگل داکس:

- منوی بالا → **"File"** → **"Version History"**  
- می‌تونید تمام تغییرات رو ببینید و برگردونید

### **۲. نظر و پیشنهاد**

- توی گوگل داکس، می‌تونید **"Suggesting Mode"** رو فعال کنید  
- بجای تغییر مستقیم، پیشنهادی می‌دهه  
- مدیر می‌تونه تموم پیشنهادات رو یکی‌یکی تأیید کند

### **۳. دسترسی‌های مختلف**

🔵 مشاهده: صرفاً مشاهده می‌کنند، نمی‌تونند تغییر بدهند

🟢 نظر: نظر و پیشنهاد بدهند، ویرایش ندارند

🟡 ویرایش: می‌تونند هرچی تغییر بدهند

### **۴. آفلاین کار کنید**

- گوگل داکس → **Settings** → **Offline** رو فعال کنید  
- توی سفر می‌تونید بدون اینترنت کار کنید  
- وصل‌شدن به اینترنت، خودکار بروز می‌کنند

## 🚀 خلاصه و سفارش

**برای حالت شما (پروپزال فنی برای تیم):**

| جزئیات | بهترین راه |
| ----: | ----: |
| **راحتی** | ⭐⭐⭐⭐⭐ راه اول |
| **دقت و خودکاری** | ⭐⭐⭐⭐⭐ راه دوم |
| **سرعت تغییرات** | ⭐⭐⭐⭐ راه دوم |
| **کار تیمی** | ⭐⭐⭐⭐⭐ راه دوم |

### **✅ سفارش نهایی:**

1. **راه دوم رو شروع کنید** (Google Drive Desktop)  
2. **نسخه Google Docs بسازید**  
3. **دوستان رو با اشتراک‌گذاری دعوت کنید**  
4. **یکسری توافق کنید:** کی لپ تاپ ویرایش کند، کی گوگل داکس (اگه از هردو استفاده کنید)

این راه بهترین تعادل بین **سادگی** و **خودکاری** رو می‌ده\! 🎯

**مشکل:** فایل توی گوگل درایو دیده نمی‌شه  
**حل:** Ctrl+R کنید تا صفحه رفرش بشه

**مشکل:** Google Docs و فایل اصلی فرق دارن  
**حل:** یکی‌یکی مقابلشون کنید و اصلاح کنید
