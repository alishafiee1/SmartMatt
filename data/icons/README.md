# RODI Smart Mattress - Web Panel Icons

این پوشه شامل ایکون‌های SVG برای پنل وب است.

## منبع
تمام ایکون‌ها از **Feather Icons** (https://feathericons.com/) انتخاب شده‌اند.

## لیست ایکون‌ها

| فایل | استفاده | رنگ پیشنهادی |
|------|---------|--------------|
| `heating-on.svg` | گرمایش فعال | نارنجی (#FF5722) |
| `heating-off.svg` | گرمایش غیرفعال | خاکستری |
| `wifi-connected.svg` | WiFi متصل | سبز (#4CAF50) |
| `wifi-disconnected.svg` | WiFi قطع | قرمز (#F44336) |
| `wifi-ap.svg` | SoftAP فعال | آبی (#2196F3) |
| `plus.svg` | افزایش دما/تایمر | - |
| `minus.svg` | کاهش دما/تایمر | - |
| `power-on.svg` | روشن | سبز (#4CAF50) |
| `power-off.svg` | خاموش | خاکستری |
| `loading.svg` | بارگذاری | آبی (#2196F3) |
| `ws-connected.svg` | WebSocket متصل | سبز |
| `ws-disconnected.svg` | WebSocket قطع | قرمز |
| `success.svg` | موفقیت | سبز (#4CAF50) |
| `error.svg` | خطا | قرمز (#F44336) |
| `clock.svg` | تایمر | - |

## حجم کل
**5.13 KB** (در محدودیت 5KB طراحی)

## استفاده در HTML

```html
<img src="/icons/heating-on.svg" alt="Heating" width="24" height="24">
```

## تغییر رنگ با CSS

```css
.icon {
  color: #FF5722; /* تمام ایکون‌ها از currentColor استفاده می‌کنند */
}
```
