# 📱 طراحی صفحه نمایش تشک هوشمند RODI
## راهنمای ساده و کاربردی

---

## 📐 چیدمان کلی صفحه

صفحه نمایش OLED با اندازه **128×64 پیکسل** به **3 قسمت عمودی** تقسیم می‌شود:

```
        32 پیکسل      64 پیکسل       32 پیکسل
    ┌──────────────┬────────────────┬──────────────┐
    │              │                │              │
    │              │   نمادها ↓     │              │
    │              │  [W] [H] [S]   │              │
    │              │                │              │
    │   دمای       │                │    تایمر     │
    │   تنظیمی     │   دمای فعلی   │   باقیمانده │
    │              │                │              │
    │   27.5°      │     25.5°      │     480      │
    │    SET       │                │     min      │
    │              │                │              │
    │              │   اطلاعات ↓    │              │
    │              │  Room: 21° 23% │              │
    │              │                │              │
    └──────────────┴────────────────┴──────────────┘
         چپ              وسط              راست
```

### توضیح قسمت‌ها:

#### 🔹 قسمت چپ (32 پیکسل):
- **دمای تنظیم شده** (Set Temperature)
- عددی که کاربر می‌خواهد تشک به آن دما برسد
- مثال: `27.5° SET`

#### 🔹 قسمت وسط (64 پیکسل):
- **دمای فعلی تشک** (بزرگترین عدد روی صفحه)
- **نمادها در بالا**: وضعیت WiFi، گرمایش، سیستم
- **اطلاعات اتاق در پایین**: دما و رطوبت اتاق
- مثال: `25.5°` با نمادها و `Room: 21° 23%`

#### 🔹 قسمت راست (32 پیکسل):
- **تایمر باقیمانده** (Remaining Timer)
- زمان باقیمانده تا خاموش شدن خودکار
- مثال: `480 min`

## 🎨 خطوط جداکننده

دو خط عمودی نازک صفحه را به 3 قسمت تقسیم می‌کنند:

```
    X=32          X=96
      ↓            ↓
      │            │
      │            │
      │            │
      │            │
      │            │
      │            │
```

- خط اول در `X=32` (بین چپ و وسط)
- خط دوم در `X=96` (بین وسط و راست)
- هر دو خط از بالا تا پایین صفحه کشیده می‌شوند

**نکته:** خطوط افقی وجود ندارد - فقط دو خط عمودی.

---

## 🔔 نمادها (Icons)

در بالای قسمت وسط، 3 نماد کوچک (8×8 پیکسل) وجود دارد:

### 1️⃣ نماد WiFi
- **روشن**: WiFi متصل است (SoftAP یا Station)
- **خاموش**: WiFi غیرفعال است

### 2️⃣ نماد گرمایش (Heating)
- **روشن**: المنت گرمایشی در حال کار است
- **خاموش**: المنت خاموش است

### 3️⃣ نماد سیستم (System)
- **روشن**: سیستم فعال و در حال مانیتورینگ است
- **خاموش**: سیستم کاملاً خاموش است

### 💡 نکته مهم:
سیستم می‌تواند **روشن** باشد (در حال مانیتورینگ دما) ولی المنت **خاموش** باشد (چون دما به حد مطلوب رسیده).

---

## 📊 اطلاعات اتاق

در پایین قسمت وسط، اطلاعات دما و رطوبت اتاق نمایش داده می‌شود:

```
Room: 21° 23%
       ↑   ↑
       │   └── رطوبت اتاق (از سنسور DHT11)
       └────── دمای اتاق (از سنسور DHT11)
```

## ✨ انیمیشن تغییرات

### مفهوم ساده:
وقتی یک عدد تغییر می‌کند، به مدت **نیم ثانیه (500ms)** با **فونت بزرگتر یا Bold** نمایش داده می‌شود.

### چه زمانی؟
- وقتی دمای تنظیمی را تغییر می‌دهید (با دکمه یا از وب)
- وقتی تایمر را تغییر می‌دهید (با دکمه یا از وب)
- وقتی دمای فعلی تغییر می‌کند (از سنسور)

### مثال:
```
حالت عادی:          حالت Bold (500ms):      بازگشت به عادی:
┌─────┐            ┌─────┐                 ┌─────┐
│27.5°│    →       │27.5°│    (500ms) →   │27.5°│
│ SET │            │ SET │                 │ SET │
└─────┘            └─────┘                 └─────┘
Font: 1            Font: 2                 Font: 1
```

**توضیح:** دمای تنظیمی تغییر کرده و به مدت 500ms با فونت بزرگتر نمایش داده می‌شود.

## 🔧 جزئیات فنی (برای برنامه‌نویس)

### مختصات دقیق:

| قسمت | X (شروع) | X (پایان) | Y (شروع) | Y (پایان) | عرض | ارتفاع |
|------|----------|-----------|----------|-----------|------|--------|
| چپ (Set Temp) | 0 | 32 | 0 | 64 | 32 | 64 |
| وسط (Main) | 32 | 96 | 0 | 64 | 64 | 64 |
| راست (Timer) | 96 | 128 | 0 | 64 | 32 | 64 |
| خط چپ | 32 | 32 | 0 | 64 | 1 | 64 |
| خط راست | 96 | 96 | 0 | 64 | 1 | 64 |

### اندازه فونت‌ها:

| عنصر | حالت عادی | حالت Bold |
|------|-----------|-----------|
| دمای تنظیمی | Font Size 1 | Font Size 2 |
| دمای فعلی | Font Size 3 | Font Size 4 |
| تایمر | Font Size 1 | Font Size 2 |
| نمادها | 8×8 پیکسل | - |
| اطلاعات اتاق | Font Size 1 | - |

### Refresh Rate:
- **5 FPS** (هر 200ms یک بار صفحه به‌روزرسانی می‌شود)
- برای صرفه‌جویی در مصرف انرژی

## 📝 خلاصه نکات کلیدی

1. ✅ صفحه به **3 قسمت عمودی** تقسیم می‌شود
2. ✅ **دو خط عمودی** از بالا تا پایین (بدون خط افقی)
3. ✅ **نمادها** فقط در بالای قسمت وسط (کوچک - 8×8)
