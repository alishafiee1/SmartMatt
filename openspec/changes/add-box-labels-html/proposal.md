## Why

محصول تشک هوشمند RODI نیاز به لیبل‌های چاپی استاندارد برای جعبه محصول دارد. این لیبل‌ها شامل لیبل پلمب (Tamper Evident Seal) و لیبل اطلاعات فنی (Product Info Label) هستند. طراحی این لیبل‌ها به صورت صفحات HTML مستقل امکان ویرایش آسان، چاپ دقیق با اندازه واقعی، و نگهداری در کنار سورس کد را فراهم می‌کند.

## What Changes

- اضافه شدن پوشه `Documents/box-labels/` برای نگهداری فایل‌های HTML لیبل‌ها
- اضافه شدن `label-seal.html` — لیبل پلمب اصالت (Tamper Evident Seal) برای درز بازشوی جعبه
- اضافه شدن `label-info.html` — لیبل اطلاعات فنی محصول برای سطح صاف جعبه
- اضافه شدن `label-config.js` — فایل پیکربندی مرکزی برای تمام داده‌های متغیر لیبل‌ها (SN، Batch، مشخصات برق، اطلاعات تماس)
- اضافه شدن `label-styles.css` — استایل‌های مشترک بین لیبل‌ها (فونت‌ها، رنگ‌ها، اندازه‌های چاپی)
- اضافه شدن `assets/` — پوشه تصاویر مورد نیاز (لوگو، آیکون‌های هشدار)

## Impact

- Affected specs: `box-labels` (new capability)
- Affected code: `Documents/box-labels/` (new directory)
- No breaking changes to existing firmware or web panel
- این تغییر کاملاً مستقل از کد فریم‌ور ESP32 است

## Design Decisions

### چرا HTML به جای ابزارهای طراحی مثل Illustrator یا Canva؟
- **نگهداری در Git**: فایل‌های متنی قابل diff و version control هستند
- **ویرایش آسان**: تغییر SN، Batch، یا اطلاعات تماس فقط در `label-config.js` انجام می‌شود
- **چاپ دقیق**: CSS print media queries اندازه دقیق میلیمتری را تضمین می‌کنند
- **بدون نیاز به نرم‌افزار خاص**: هر مرورگر مدرن کافی است

### چرا `label-config.js` جداگانه؟
- تمام داده‌های متغیر (SN، Batch، مشخصات برق، QR URL، اطلاعات تماس) در یک فایل
- برای چاپ سری، فقط این فایل تغییر می‌کند
- خطای انسانی (فراموش کردن آپدیت یک لیبل) به حداقل می‌رسد

### اندازه‌های پیشنهادی لیبل‌ها
- **لیبل پلمب**: 100mm × 30mm (مناسب برای درز جعبه)
- **لیبل اطلاعات**: 100mm × 150mm یا 80mm × 120mm (بسته به ابعاد جعبه نهایی — قابل تنظیم در CSS)

## فاز بعد: دفترچه راهنمای محصول

پیشنهادات برای فاز بعد (خارج از scope این proposal):

### گزینه A: HTML Multi-Page (توصیه شده)
- ادامه همان رویکرد HTML — یک فایل `manual.html` با چند صفحه print
- مزیت: سازگار با workflow فعلی، قابل نگهداری در Git
- مناسب برای: دفترچه ۴ تا ۸ صفحه‌ای

### گزینه B: Markdown → PDF
- نوشتن محتوا در Markdown، تبدیل به PDF با ابزارهایی مثل Pandoc یا md-to-pdf
- مزیت: محتوا کاملاً متنی و قابل جستجو
- مناسب برای: دفترچه‌های طولانی‌تر با نیاز به فهرست مطالب

### محتوای پیشنهادی دفترچه راهنما
1. معرفی محصول و اجزا
2. راهنمای نصب و راه‌اندازی اولیه
3. اتصال به WiFi (SoftAP + Station)
4. استفاده از پنل فیزیکی (دکمه‌ها)
5. استفاده از پنل وب
6. استفاده از اپلیکیشن اندروید
7. تنظیم دما و تایمر
8. هشدارهای ایمنی
9. عیب‌یابی (Troubleshooting)
10. اطلاعات گارانتی و پشتیبانی
