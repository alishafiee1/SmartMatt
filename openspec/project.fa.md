## زمینه پروژه

### هدف
تشک هوشمند RODI یک دستگاه اینترنت اشیاء (IoT) است که کنترل هوشمند دمای تشک را با استفاده از المنت حرارتی فراهم می‌کند. این سیستم به کاربران اجازه می‌دهد دما و زمان‌بندی را از طریق چندین رابط (پنل خود دستگاه، پنل وب و اپلیکیشن اندروید) با استفاده از دسترسی مستقیم WiFi و اتصال به شبکه محلی کنترل کنند.

### تکنولوژی‌های مورد استفاده
- **میکروکنترلر**: ESP32 (فریم‌ورک ESP-IDF)
- **سنسورها**:
  - DHT11 (دما و رطوبت محیط)
  - DS18B20 (دمای داخلی تشک)
- **نمایشگر**: OLED SSD1306
- **ارتباطات**: WiFi (SoftAP + Station)، WebSocket، REST API
- **ذخیره‌سازی**: کتابخانه Preferences در ESP32 (NVS)
- **فرانت‌اند**: پنل وب (HTML/CSS/JavaScript)
- **موبایل**: اپلیکیشن اندروید

### قراردادهای پروژه

#### سبک کدنویسی
- **معماری**: ساختار پوشه‌ها بر اساس قابلیت (Feature-based)
- **زبان**: ++C برای فریم‌ورک ESP-IDF
- **کامنت‌ها**: فقط به زبان انگلیسی
- **قرارداد نام‌گذاری**:
  - کلاس‌ها: PascalCase
  - متغیرها: camelCase
  - ثابت‌ها: UPPER_SNAKE_CASE
  - پایه‌های سخت‌افزاری (Pinها): در ابتدای برنامه تعریف می‌شوند
- **سازمان‌دهی فایل‌ها**: استفاده از کلاس‌های هدر برای ماژول‌های میکروکنترلر
- **کیفیت کد**: کد تمیز، استاندارد و خوش‌ساختار

#### الگوهای معماری
- **ساختار مبتنی بر قابلیت**: سازمان‌دهی بر اساس وظایف (سنسورها، نمایشگر، گرمایش، شبکه و غیره)
- **دسترسی مستقیم WiFi**: ESP32 به عنوان SoftAP برای کار بدون نیاز به اینترنت
- **ارتباط ترکیبی**:
  - WebSocket برای ارسال داده‌های بلادرنگ (کانال Push)
  - REST API برای فرمان‌ها و تنظیمات
- **استراتژی ارسال داده**:
  - ارسال فقط در صورت تغییر (Option=CHANGE)
  - ارسال اسنپ‌شات کامل در اتصال اولیه (Option=ALL)
- **تایمر سمت سرور**: شمارش معکوس تایمر در فریمور انجام می‌شود؛ کلاینت‌ها تنها مدت زمان را نمایش می‌دهند و زمان باقی‌مانده را از طریق WebSocket دریافت می‌کنند.
- **استاندارد JSON**: تمام پیام‌ها و پاسخ‌های API در قالب JSON هستند.

#### استراتژی تست
- **اولویت با ایمنی**: خرابی سنسور = خاموش شدن المنت گرمایشی
- **واچ‌داگ تایمر**: برای اطمینان از پایداری سیستم فعال است
- **حالت پیش‌فرض امن**: سیستم گرمایشی در هنگام بوت/ریست خاموش است
- **اعتبارسنجی محدوده‌ها**:
  - دما: ۲۰ تا ۴۵ درجه سانتی‌گراد
  - تایمر: ۱۰ دقیقه تا ۸ ساعت (پیکربندی فعلی؛ وابسته به `TIMER_MIN_MIN` و `TIMER_MAX_MIN`)
  - هیسترزیس: ۲ درجه سانتی‌گراد (قابل تنظیم)

## زمینه دامنه
- **دستگاه هوشمند خانگی IoT**: سیستم گرمایش تشک با کنترل دما
- **رابط‌های کاربری**:
  1. پنل فیزیکی با دکمه‌ها (روی دستگاه)
  2. پنل وب (از طریق مرورگر با SoftAP یا LAN)
  3. اپلیکیشن اندروید
- **ایمنی حیاتی**: خرابی سنسور دما باید بلافاصله موجب خاموش شدن گرمایش شود
- **تنظیمات پایدار**: اطلاعاتی مانند مشخصات WiFi، نقطه تنظیم دما و تایمر در NVS ذخیره می‌شود
- **مقادیر پیش‌فرض**: دمای ۲۵ درجه سانتی‌گراد، گرمایش خاموش در شروع
- **رفتار دکمه‌ها**:
  - فشار کوتاه: ±۱ درجه سانتی‌گراد یا ±۱۵ دقیقه
  - فشار طولانی: تغییر سریع‌تر
  - نگه‌داشتن دکمه پاور (۳ ثانیه): روشن/خاموش کردن SoftAP
- **چیدمان نمایشگر**:
  - مرکز: دمای محیط و رطوبت
  - راست: زمان باقی‌مانده تایمر
  - چپ: نقطه تنظیم دما
  - بالا-راست: آیکون WiFi
  - بالا-چپ: آیکون المنت گرمایشی

## محدودیت‌های مهم
- **محدوده دما**: ۲۰ تا ۴۵ درجه سانتی‌گراد (برای ایمنی)
- **محدوده تایمر**: ۱۵ دقیقه تا ۸ ساعت
- **هیسترزیس دما**: ۲ درجه سانتی‌گراد (قابل تنظیم در کد)
- **دمای پیش‌فرض**: ۲۵ درجه سانتی‌گراد
- **دقت تایمر**: استفاده از تایمر داخلی ESP32 (دقت خیلی بالا لازم نیست)
- **پروتکل ایمنی**: قطع شدن سنسور دمای تشک = خاموش شدن المنت + نمایش پیام خطا
- **دنباله بوت**:
  1. نمایش انیمیشن Rodiset.ir
  2. نمایش عبارت "RODI" با فونت بزرگ (۳ ثانیه)
  3. راه‌اندازی سخت‌افزار و ورود به حالت عادی کار
- **شبکه**: باید بدون اینترنت نیز کار کند (حالت SoftAP)
- **ذخیره‌سازی**: استفاده از کتابخانه سبک Preferences برای ماندگاری تنظیمات

## وابستگی‌های خارجی
- **فریم‌ورک ESP-IDF**: فریم‌ورک اصلی توسعه
- **سنسورها**:
  - کتابخانه DHT11 برای دما/رطوبت
  - OneWire/DallasTemperature برای DS18B20
- **نمایشگر**:
  - درایور OLED SSD1306
  - انیمیشن سفارشی برای نمایش تغییر وضعیت‌ها
- **شبکه**:
  - استک WiFi روی ESP32 (حالت‌های SoftAP و Station)
  - کتابخانه WebSocket برای ارتباط بلادرنگ
  - سرور HTTP برای REST API
- **ذخیره‌سازی**: کتابخانه Preferences (لایه Wrapper روی NVS)
- **Android SDK**: برای توسعه اپلیکیشن موبایل

## قابلیت‌های سیستم
- مانیتورینگ بلادرنگ دما (محیط و تشک)
- کنترل المنت گرمایشی با استفاده از هیسترزیس
- خاموش شدن خودکار بر اساس تایمر
- کنترل از چند رابط (پنل، وب، موبایل)
- دسترسی مستقیم WiFi (SoftAP)
- ادغام در شبکه محلی (پیکربندی WiFi)
- ذخیره‌سازی پایدار تنظیمات
- امکانات ایمنی (پایش سنسورها، واچ‌داگ)
- بازخورد بصری (انیمیشن‌ها و آیکون‌ها روی OLED)
